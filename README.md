# Sign-Up Page 📄

> A Modern, Responsive **Dark-Themed Authentication UI** Built with HTML, CSS and JavaScript.

This project is built for creating a clean and stylish frontend authentication experience with animated Sign In / Sign Up panels, social login buttons, dark UI elements and responsive styling.
